🔍 FactSure — AI-Powered Misinformation Detection Platform

FactSure is an AI-powered platform designed to identify, analyze, and verify misinformation across web and social media content. It enables users to submit claims, news links, images, or videos and receive AI-assisted fact verification using autonomous agents, NLP, and media analysis.

The platform focuses on accessibility, trust, and real-time verification, making fact-checking easier for everyday users.

🚀 Key Features

Claim & Content Verification
Users can submit text claims, URLs, images, or videos for verification.

Autonomous AI Agents
Multiple AI agents collaborate to scrape sources, cross-check claims, and validate information.

Multi-Modal Analysis
Supports text, image, and document-based verification using NLP and media understanding techniques.

Social Media–Style Interface
Intuitive UI inspired by social platforms to encourage user engagement.

Chrome Extension Integration
Enables instant verification directly on platforms like Instagram and X (Twitter).
